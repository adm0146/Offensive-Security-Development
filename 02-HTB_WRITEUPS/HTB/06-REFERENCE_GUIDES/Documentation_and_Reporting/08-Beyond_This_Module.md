# Section 08 — Beyond This Module

> **Lab: no** — Reading-only section with practice recommendations and next steps.

**Core principle:** Documentation and reporting is a skill that improves only with practice. Approach every box, lab, and module as if it were a real engagement. Write findings professionally, maintain a findings database, and seek feedback.

---

## Practice opportunities

| Activity | What to Practice |
|----------|-----------------|
| HTB boxes (active/retired) | Full notetaking structure, enumerate → exploit → document |
| Pro Labs / End Games | Multi-host attack chains, full report writeup |
| Academy modules | Per-section notes, finding writeups for key vulnerabilities |
| CTFs | Speed documentation, evidence capture under time pressure |
| Personal blog | Walkthroughs, technique deep-dives, writing clarity |
| Peer review | Share writings, get feedback, read others' blogs |

---

## Building a findings database

- Write 1-2 findings professionally for every box you play (even if no full report)
- Over time, builds a sanitized findings database for real engagements
- Customize per client but start from templated findings
- Use WriteHat, Ghostwriter, Dradis, or a simple Markdown folder
