# Section 1 — Intro to Attacking Enterprise Networks

> Capstone module for the Penetration Tester Job Role Path. Simulates a full External Penetration Test against Inlanefreight that transitions into an Internal Penetration Test. Chains together all 27 preceding modules into a single engagement.

---

## Module Purpose

- Practice everything learned across all modules against a simulated corporate network
- Walk through each step from a pentester's perspective, including dead ends and the reasoning behind each decision
- Structured as a guided "ride-along" — the module walks through the thought process, but you execute everything and submit each flag

## What Makes This Different from Skills Assessments

- No pre-knowledge of which techniques apply — you have to recognize what you're looking at and pick the right tool
- Constantly cycling between phases: info gathering -> web attacks -> network attacks -> AD attacks -> privilege escalation -> pivoting -> lateral movement
- Targets are a mix of web applications, standalone Windows/Linux hosts, and Active Directory

## Pentest Phases Covered

1. Pre-Engagement
2. Information Gathering
3. Vulnerability Assessment
4. Exploitation
5. Post-Exploitation
6. Lateral Movement
7. Proof of Concept
8. Post-Engagement
